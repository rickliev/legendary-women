# Legendary Women

The League of Legendary Women is a mobile-first static catalog built with Astro and TypeScript.

## Local development

```powershell
npm install
npm run dev
```

Open `http://localhost:4321`.

## Check and build

```powershell
npm test
npm run check
npm run build
```

Catalog records live in `src\data\women.json`; portraits live in `public\images\women`.

The application builds to static files in `dist\` and is prepared for deployment to Azure Static Web Apps.
